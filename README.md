# RREO Anexo 7 — Demonstrativo dos Restos a Pagar por Poder e Órgão (SEFAZ/RN)

Aplicação web interativa para elaboração, conferência, importação de relatórios PDF do SIGEF/RN e exportação em Excel (`.xlsx` formulado) e PDF oficial do **Anexo 7 do Relatório Resumido da Execução Orçamentária (RREO)** do Estado do Rio Grande do Norte (LRF, art. 53, inciso V; MDF 15ª Edição / MCASP 11ª Edição).

## Como publicar no GitHub Pages
1. Suba o arquivo `index.html` na raiz do seu repositório público no GitHub.
2. Em **Settings > Pages**, selecione a branch `main` (pasta `/ (root)`) e clique em **Save**.
